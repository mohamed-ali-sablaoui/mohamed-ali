# Mohamed Ali Sablaoui — Portfolio

Portfolio personnel bilingue (français / anglais), réalisé en HTML5, CSS3 et JavaScript vanilla.

## Aperçu local
Ouvrir `index.html` dans un navigateur.

## Publication sur GitHub Pages
1. Créer ou ouvrir le dépôt `mohamed-ali-sablaoui.github.io`.
2. Ajouter le contenu de ce dossier à la racine du dépôt.
3. Dans Settings → Pages, choisir la branche principale et le dossier `/ (root)`.
4. Enregistrer et attendre la publication.

## Personnalisation
- Portrait : `assets/portrait.png`
- Styles : `css/style.css`
- Interactions et langue : `js/main.js`
- CV : placer le fichier `CV-Mohamed-Ali-Sablaoui.pdf` dans `assets/` pour activer le bouton de téléchargement.

La section Projects est volontairement vide et prête à recevoir les projets réels.
